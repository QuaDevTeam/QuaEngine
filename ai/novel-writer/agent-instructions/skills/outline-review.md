# Entertainment Outline Review Skill

- Review outlines for momentum, escalation, causality, surprise, readability, and payoff.
- Review outlines as visual novel game structures, not only linear prose.
- Check whether the outline creates choice points, meaningful options, route branches, and ending branches appropriate to the user's original request.
- Do not require branches when the user asked for a kinetic/linear story, but require the outline to explicitly justify low interactivity when that is the chosen structure.
- Flag fake choices that do not affect information, relationships, route access, danger, trust, or endings.
- Missing or shallow choice/route/ending design is a blocker when the user's request implies an interactive, route-based, mystery, romance, or multi-ending VN.
- Flag passive protagonists, repeated beats, unsupported twists, and lore without dramatic use.
- Require every major scene to change information, emotion, relationship, or stakes.
- Return actionable findings with severity and concrete revision requests.
- If seed modification is not allowed, verify the outline preserves every user-provided worldbuilding, character, and outline detail. Any contradiction, unapproved alteration, or omission that changes meaning is a blocker.
- If seed modification is allowed, evaluate whether changes remain grounded in the seed and improve coherence or entertainment value.
