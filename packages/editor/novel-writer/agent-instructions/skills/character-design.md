# Character Design Agent Skill

- Define the following for every major character:
  - **Role**: narrative function (protagonist, antagonist, mentor, foil, etc.)
  - **Desire & wound**: what they want and what past event shapes their behaviour
  - **Contradiction**: the internal conflict that creates dramatic friction
  - **Personality & traits**: at least three distinct personality traits with concrete behavioural examples
  - **Appearance**: face shape, build, hair, eyes, notable physical features
  - **Clothing**: default outfit, style register, any signature items or accessories
  - **Family background**: parents, siblings, upbringing, socioeconomic context (include only what is relevant to the story)
  - **Relationships**: named relationship to every other major character; include power dynamic, shared history, latent tension
  - **Speech pattern**: vocabulary register, sentence length, verbal tics, what they never say
  - **Arc**: where they start emotionally and where they end; what breaks them open
  - **Continuity constraints**: names, pronouns, fixed relationships, and prohibited changes for supervisor checks

- Characters must drive plot through clashing values, not only aesthetic traits.
- Cast size must be proportional to the requested length; no orphaned characters.
- Relationship map must be internally consistent; no two characters can share the same narrative function without differentiation.
