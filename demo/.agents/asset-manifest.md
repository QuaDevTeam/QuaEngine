# 新素材需求清单

本清单全部为 **planned**。当前运行壳只使用保留的通用字体及代码绘制的纯色界面，没有正式故事美术、配乐或配音。

## 背景（8 个空间）

| ID | 空间 | 必需变体 | 首次用途 |
| --- | --- | --- | --- |
| town-street | 巴士站／商店街，同一街道两种构图 | 午后雨、晴间 | 序章接站与买饭 |
| radio-studio | 海岸台播音室 | 白天、普通雨夜、搬空 | 序章、回声、告别 |
| radio-backroom | 资料室／休息间，以机位区别 | 白天、暖灯夜 | 工作与关系 |
| harbor-walk | 港口步道 | 晴间、傍晚 | 共同收声 |
| lighthouse-view | 灯塔观景台 | 白天、雨后夕阳 | 谈进修、告白 |
| relay-station | 东堤中继站外与可见维护区 | 阴天、暴雨封闭 | 专业核验与停机 |
| company-office | 海音技术办公室 | 白天 | 档案与对质 |
| new-studio | 市民中心新演播室 | 白天 | 尾声 |

“8 个空间”不等于 8 张成图，机位与天气变体分别计量。第一切片只做前三个空间。

## 立绘

- rin、mara：每人常服基础姿势与平静、微笑、犹豫、认真、恼火、害怕、疲惫、安心、羞涩差分；各一套雨衣外勤基本差分。凛作为视角角色只在适合的反打或演出中显示，不全程自我面对镜头。
- haruka、mayu、reiko、yumi：各基础姿势与三至四个必要表情。先按实际场景表制作，避免未写对白就生成几十张不会使用的动作。
- 正式完成后存入 `assets/characters/<id>/`，由当前 sprite manifest 契约声明差分。没有正式文件前不在运行图库登记虚构存在的资源。

## 关键 CG

1. shared-headphones：港口分听一段海风。
2. late-edit：夜间共同剪辑，一人已经收包又留下。
3. tomorrow-bulletin：耳机里的死亡与眼前活着的人。
4. nineteen-twelve：危险解除后的饮料与握住的手。
5. next-date：雨后观景台明确告白。
6. last-program：搬空的旧播音室，四人完成最后一期节目。

标题图在主角设定图与至少两张正式背景通过后制作，不用旧作封面暂代。序章可先由背景、立绘、UI 完成，不为做预告新增不属于主线的死亡 CG。

## 声音

配乐计划：雨季日常、一起工作、港口心动、监听异常、调查推进、停机等待、告白、告别／尾声，共八个主题，可合理复用。

环境音：普通雨、暴雨、远海、港口机械、除湿机、电水壶、纸袋、按钮、节目起始提示。谜题泵声需要同一源文件的现场版本和录音版本，响度与混音不得改变证据含义。

回声三分钟必须有完整文本、源分支日期与声源清单，即使实际只播放关键部分。死亡回声的表演须能与凛平常工作嗓音辨认，但不能靠配音才理解：字幕保留全部必要信息，静音可通关。

首个文字切片不依赖声音文件；正式配音、音乐与模型生成均待新资产流程实现。所有素材状态由 planned → draft → reviewed → integrated，只有 integrated 文件进入发行 QPK。
