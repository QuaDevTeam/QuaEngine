# 通俗用语复核

2026-09-08。承接文学润色，对全部14份QS做用词和搭配检查，修改日常对白、工作说明、旁白及一个选项的显示文字。没有扩展场卡或改变故事规则。

## 发现与修改

- 创作摘要中把“吃到辣椒时的反应”压缩成了不常用的食物简称，已改为“Mara吃到辣椒时的反应，以及剪辑时长带来的取舍”。摘要同样需要通顺中文。
- 单字“核”反复代替不同动作，读者需要猜。例如“核接口”改为“检查接口”，“核对照记录”改为“核对之前的测试记录”；因动作不同，分别使用检查、核对、查明和确认。
- 私下说“我不是来催交付”不符合谈作品的口吻，改成“我又不是来催你交作品的”。凛的简短解释与想留下的心意仍由后面的放包、落座承接。
- “复接”“收文记录”“原轨”等过于简略的说法，按上下文改为重新接线、通知的接收登记表、原始录音。选项现在显示“先核对节目的原始录音”；选择ID不变，相关浏览器选择文字已同步。
- “签阅范围”改为说清哪份报告由谁看过并签字、谁作了解释；“材料收取与后续核对已经闭合”改为每份收到的材料都已核对完毕。看过报告、批准试验和施工责任仍分别交代。
- 停机通知明确两路电源切断并隔离、剩余能量处理、机器本地定时试验计划清除、现场独立核验。没有用口语化省掉安全事实或改变行动时刻。
- 咖啡厅漫画里的鞋补足先刷洗、再晾晒的动作，由Mara指出有些鞋不能泡水，避免前后句的担心没有依据。
