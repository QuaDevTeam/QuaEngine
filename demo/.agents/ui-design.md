# 游戏界面规范

本轮落实范围为 Web demo 的产品界面。以暖白和海绿色配合故事环境。界面主要显示操作和阅读内容，不反复摆放电台名称、主题标语与栏目眉题。图片按用户要求延期，本轮不生成任何图片或替代场景画。

## 视觉规范

- 纸面 `#f5f3eb`，纸卡 `#fffdf7`，正文墨绿 `#29453f`，次级文字 `#61736b`，交互海绿 `#42796e`，细线 `#c7d2c5`，分区浅绿 `#e3ebe2`。全界面共用，不再将主菜单和游戏内面板分成两种主题。
- 标题采用已打包的 Noto Serif；正文和控件采用 Noto Sans。正文 30、姓名 25、设置标签 23、设置说明 17、工具条 20，均为逻辑舞台单位。字号不随浏览器窗口另外切换。
- 海绿实底表示主要操作或正在启用的自动／快进；悬停为浅绿底，键盘焦点为外侧清晰描边。禁用动作同时使用真实 disabled 属性。取消、关闭和恢复默认保持次级层级。
- 面板以细线分隔。设置分组不用色块与竖条堆叠强调；已移除各面板的“海岸台／…”眉题。

纸张颗粒由样式表内嵌 SVG 的静态程序噪声组成，统一用于标题、目录、系统面板和对话框。不添加外部图片请求、噪点动画或影响点击的纹理覆盖层；纹理对比度低于分隔线，正文对比度保持不变。

## 页面布局

- 标题页：作品名、英文名和竖向菜单。删除顶部时间地点标签与宣传句，剧情阅读时不重复显示作品名。背景图未接入时使用暖白纸色与低对比度细颗粒纹理。
- 对话：安全区左右各留 5%，底部留 5%，最小高度 250。正文高度可随内容增长；下方独立预留 76 的工具区域。姓名、正文、细线、右下方四个动作形成一张完整的阅读笺。旁白仍然没有说话人。
- 选择：对话上方居中，最大宽度 1040，可换行；海绿左边线区分可选择的回应。
- 设置：1360 宽、高度按内容排列的面板，左侧为阅读速度、自动间隔和快进范围，右侧为操作与显示。六个当前设置在一屏内完整呈现。使用真实 range/select/switch，滑块支持拖动和方向键，并提供文字化数值给读屏器。偏好继续由设置插件保存，UI 不持有偏好副本。
- 菜单：700 宽的纸卡，继续阅读为主要操作，其余阅读动作有清楚的顺序；背后正文变暗并停止交互。
- 存读档：1360 × 820，三列九格，编号、章节和保存时间分层，空位采用虚线；覆盖确认沿用相同标题与操作语言。
- 对话记录：1460 × 930，页头和底部位置操作固定，中间连续滚动。对白的姓名与正文对齐，旁白使用整行宽度；不再为每句话加横线。打开时定位最近记录，支持“最早记录／最近记录”和聚焦列表后的键盘滚动。回看遮罩隐藏原对白，关闭后返回阅读；仍使用官方记录组件与插件意图。隐藏机器时间、条目索引和重复的选项摘要。
- 章节选择：两栏目录，按左栏从上到下、再到右栏的顺序排列。每行显示正常章名（序章、第一章至第七章、尾声）、标题和日期，整行点击从章首重读；当前章节标注“上次读到”，不根据章号推断完成情况。未读标题隐藏为“尚未阅读”，不能点击。

## 实现边界

`src/targets/web/main.ts` 仅显式导入 renderer 的结构样式与 demo 自有主题；不再导入默认暗色主题和默认章节主题。产品样式由 `src/game/styles.scss` 的六个入口组成：基础、外壳、对话、系统面板、标题与章节、动效。移除旧的 gallery、responsive、render-parity 样式，避免重复覆盖。图库继续隐藏，正式美术接入后再制作其页面。

所有位置仍在引擎逻辑舞台上创作，由 renderer 的已有布局适配缩放到屏幕；不使用 viewport 单位改变剧情坐标。主菜单、存读档、回看、设置和剧情导航沿用现有插件投影与 pipeline。Web 的新主题没有改动 native 的 QSS 或原生功能面板，本轮截图与视觉验收不代表原生主题已经同步；共享剧情和导航协议保持原状。

## 验证

- `pnpm --filter demo typecheck` 与 `pnpm --filter demo build`。
- 启动生产预览后运行 `pnpm --filter demo test:story`：故事三结局、存读档、续读、章节选择及生产 QPK 回归。
- `pnpm --filter demo test:ui`：真实界面截图、所有设置在面板内、滑块键盘更新跨刷新保留、自动模式 aria-pressed、正文和工具条不重叠、平板与手机横屏的舞台边界和浏览器错误检查。可用 `QUA_STORY_URL` 指定预览地址。
- 截图在忽略目录 `.generated/qa/ui/` 与 `.generated/qa/story/`。这些是当前纯文字阶段的产品界面记录，不是最终音画演出验收。

## 界面文案

菜单采用常用名称，例如“设置”“保存进度”“返回标题”。按钮文字不解释系统实现。“续读点”“外部保全”等只在确有必要的故事或开发语境出现。

返回标题时说明当前进度会自动保存；覆盖存档时说明无法恢复；章节重读说明从章首开始。其余面板不重复讲存档规则。结局页显示结局名称与类型，不替玩家总结人物关系、案件经过或作品主旨。

剧情画面不显示常驻作品名、副标题或左上角铭牌。原生端的旧 title-plate 组件、样式和专用文案已移除；作品正式标题仍用于主菜单。

设置页选择框：保留真实 select，关闭浏览器默认箭头，以 24 × 24 的圆角线条 SVG 显示单个向下箭头。控件高度 60，右侧为箭头留出 66 的文字间距；箭头不拦截点击、不进入读屏名称。悬停、键盘聚焦和禁用状态各有明确样式，弹出的选项列表仍沿用系统原生交互。
