# 叙事根基与世界观设定

## 作品定位

《明天，请再一次呼唤我》（*Call Me Again Tomorrow*）是一部以 2019 年初夏日本海滨小城“青叶市”为舞台的**声学悬疑 × 女性情感（百合）视觉小说**。

故事拒绝将人物简化为背诵规章制度的传声筒，也拒绝把生死危机写成“坐在办公室里等电话和传真”的行政走流程。它以**声音修复师神代凛**与**地方电台青年编导 Mara**从陌生、共鸣、心动、隐瞒与裂痕，到暴雨夜并肩破局、最终在平凡晴日里相爱的完整情感弧线为核心，将“二十四小时后的未来广播回声”与“海港小镇的人情记忆、工程谎言与生死抉择”紧密编织在一起。

## 日式悬疑视觉小说（ADV）×“以对话为主、短平快”行文规范

1. **对话驱动故事推进（Dialogue-Driven Progression，对白占比 ≥ 70%）**
   - 视觉小说的核心魅力在于**立绘角色之间的实时互动与声音交锋**。故事推进、线索推理、过往回忆与情感升温必须**以人物对话为主（全篇对白行数占比 ≥ 70%）**。
   - 严禁出现连续五六行以上无人开口的纯第三人称独白或背景设定科普。需要交代背景、声学原理或心理过往时，必须转化为角色之间的问答、吐槽、试探与倾诉；旁白仅作为对白之间的**一两行动作支点、环境切面或呼吸停顿**。
2. **一击一节拍（One Beat per Click）与短平快节奏**
   - 在视觉小说的对话框（Textbox）交互中，剧本里的**每一行就是玩家的一次点击（Click）与一个镜头节拍**。
   - 日常旁白与角色对白单行以 **8～28 字**为佳，单次渲染到对话框的文本（包括 `${scope.pick}` 与 `${scope.response}` 的单个分支）**不超过 38 个汉字**，全篇平均单行字数控制在 **18～24 字**左右。
   - 遇到紧张的悬疑对峙、暴雨抢险或细腻的情感停顿时，积极使用 **4～14 字的短促单行**来加快点击节奏、制造呼吸感。
3. **日式悬疑与二次元视觉小说语感（Japanese Mystery VN & Anime Tone）**
   - **彻底根除现代中国网文腔与行政公文腔**：严禁出现“安监科督察员”、“联合调查组执法专车”、“特种作业票”、“阴阳台账”、“骑缝章”、“倒吸一口凉气”、“撕下遮羞布”、“定海神针”、“老伙计”、“查岗”、“大事化小”等出戏词汇。
   - **贴合 2019 年日本海滨小城（青叶市）与二次元日常质感**：使用符合日本地方生活与视觉小说语境的风物细节——商店街（アーケード）、防波堤、白岛灯塔、梅雨与紫阳花、自动贩卖机的白桃汽水、奶油面包（クリームパン）、便当与麦茶、开盘磁带、ON AIR 红灯、海音科技（Kai-on）研究所、市役所防灾课。
   - **鲜明的二次元角色属性与反差萌**：
     - **神代凛（Rin）**：冷淡认真的声学狂热者 + 生活略带天然呆（永远忘带伞、对距离感迟钝、被撩会耳根发红结巴）。
     - **Mara**：元气直球 + 带点小恶魔促狭的地方电台少女（爱画火柴人涂鸦、主动分享耳机与汽水、面对死亡预告时既会委屈落泪又格外勇敢）。
     - **水野春香（Haruka）**：冒失元气的后辈播音员（宝贝蓝鲸马克杯、自带气氛组吐槽役）。
     - **青木由美（Yumi）**：成熟可靠的电台台长大姐姐。
     - **高桥真由（Mayu）**：顶着黑眼圈、穿白大褂、泡面维生的电波系研究员，在最后关头亲手烧毁五年心血救下 Mara。
     - **森田礼子（Reiko）**：笑容礼貌客套、实则冷酷算计的企业精英，用伪造的绿色安全指示灯（`STATUS: GREEN`）掩盖致命隐患。
   - **善用 QuaScript 演出指令**：伴随对白切换密集配合 `@SetExpression`（`neutral` / `focused` / `surprised` / `warm` / `guarded` / `pain` / ` resolute` / `smile`）、`@MoveCharacter` 与 `@AnimationTimeline`，让舞台画面始终处于鲜活演出的状态。
4. **乒乓式对白（Ping-Pong Dialogue）与动作留白**
   - 任何超过两层意思的台词，必须拆解为角色之间你来我往的短句交锋。
   - 不替玩家做阅读理解式的心理总结，只写具体动作（如“Mara 在桌下伸出手，勾住了她微凉的小指”），把情绪留给画面与玩家的体验。


## 核心设定：每日三分钟的“明日回声”

1. **物理载体与触发窗口**
   - 青叶海岸广播电台旧楼与东堤信号中继站建在同一段海岬岩基上，共用一条地下管廊。
   - 高桥真由团队借用中继站与旧楼侧间，开展为期五年的“近海大气波导与长基线信号延迟校准”实验。由于海底含水断层在六月梅雨季水位暴涨，加上两套非对称相位补偿阵列形成了不可逆的量子/电磁锁相配对，每日 **20:00 至 20:03** 的高功率校准脉冲，会将**二十四小时后同一频段（次日 20:00–20:03）的广播调制包络**耦合进旧楼那根未彻底剪断的备用返送监听线（Return Line 2）中。
   - **不可复制与不可调谐**：这一现象只能被动接收次日 20:00–20:03 的三分钟残响，无法调整时间跨度，无法向过去发送长篇数据，一旦配对阵列的储能环被强行熔断泄放，回声通道便会永久消失。

2. **回声的三条叙事铁律（支撑三次小悬疑与终局大逆转）**
   - **铁律一：回声是“未收到预警的源分支”残影，未来可以被改变**
     - 当今晚 20:00 听见明晚的广播时，那段声音来自“假设今晚没有听见这段回声、按原轨迹自然发展”的明天。一旦今晚的人们根据回声采取了行动（例如收起马克杯、提前拨打电话），现实就会偏离回声，而已录下的回声母带本身不会像魔术字迹一样自动改写。
   - **铁律二：三分钟的声音只有波形，没有空间与因果上下文（照相馆铜铃之谜 & 鱼市错位采访）**
     - 声音会忠实记录物体振动的频率，却会剥离画面与前因后果。听见“照相馆关门前的第三声迟滞铜铃”，人们会误以为旧店重开；听见“鱼市采访缺席致歉”，人们会用剪辑技巧强行拼凑一段看似完美的对谈。**“以为听见了声音就等于掌握了真相”，是人类最容易踏入的认知陷阱。**
   - **铁律三：当系统存在隐蔽的“双胞胎通路”时，锁住表面那一把伞无法阻止结局（两把蓝伞之谜 -> 绿色指示灯与双回路陷阱）**
     - 第三章里，Mara 把带有“歪斜红线与三道白胶带”的深蓝雨伞锁进铁柜，次日失物招领广播却依旧一字不差地响起——因为社区曾用同一卷红线修补过两把外观几乎一样的旧伞。
     - 这一日常悬疑直接映射第五、六章的终极诡计：**为什么取消了 Mara 的常规外勤、远程监控屏也亮起绿灯（显示主电源已停机），源分支里的 Mara 依然会在 19:12 死于东堤共用维护廊？** 因为中继站同样存在一条隐蔽的“第二通路”（因硬件卡死而被礼子用软件补丁伪装成绿灯的辅助储能环路），以及一条只有电台外勤才会触发的“第二动线”（18:40 离线高负荷测试引发地下电缆沟短路 -> 烧断同管廊的海岸台防汛应急广播主干 -> 远程屏依然显示安全的绿灯 -> 把毫不知情的 Mara 诱入走廊切换应急跳线）。

## 人物塑造与文风准则

- **去 AI 味与文学质感**：摒弃空洞的成语堆砌（如“赫然写着”“死死盯着”“心如刀割”“字正腔圆”）和机械的公文式对白。用初夏梅雨的潮气、磁带氧化层的铁锈味、滚筒烘干机的暖风、耳机分线器拉扯的微弱力道、欲言又止的呼吸停顿来承载情绪。
- **声音作为情感的媒介**：神代凛是因为曾过度降噪抹去逝者笑声前的喘息、被家属评价“不像她了”而背负心理阴影的修复师；Mara 是用整个青春记住海港街坊声音、却在离开与留下之间犹豫的年轻采编。凛从“只敢修补过去的声音”走向“为了眼前的活人打破封闭”，Mara 从“总是照顾所有人”走向“坦诚面对自己的渴望与恐惧”。
- **视角规范**：全篇采用紧贴神代凛的第三人称有限视角（叙述中称“神代凛 / 凛 / 她”，对白与消息中使用第一人称“我”）。
