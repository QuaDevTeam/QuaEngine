## 标题

中文：**明天，请再一次呼唤我**。日文：**明日、もう一度わたしを呼んで**。英文工作名：**Call Me Again Tomorrow**。

“明天”指向只能提前一天收到的广播；“呼唤我”同时指向声音工作、逐步改变的称呼和危险之后仍愿意回应的关系。序章不把标题当预言台词，尾声以两人在普通电话中约定下一次录音回应题意，不新增循环与失忆。技术 ID 为 `call-me-tomorrow`，项目包名为 `dev.quajs.demo.callmetomorrow`。

- 2047 年，虚构日本海岸城市青叶市，初夏梅雨。核心异常是收到明天的三分钟广播。
- 完整救下重要人物、确认恋人关系；代价是放弃时间通信装置与原来的工作据点，接受无法预知的生活。
- 神代凛与 Mara 仅延续名字（神代已改名为凛）和发型识别；服装、职业、经历、关系均重新设计。其余人物与舞台为新设定。

## 阅读顺序与职责

按最新悬疑方向扩写时，先读 [故事入口与悬疑递进](narrative-foundation.md)：两人为何相遇、研究为何存在、为何收到死亡通报、以及凛从怀疑到隐瞒和救人的心理链。第四章现跨六月二十二日晚至二十三日08:45；次晨既有维护回电触发揭露，替代上一轮当晚立即共享的设计。世界观另附可融入序章的开场短段。主线仍为89场、114,500字预算，当前QS已经接入这条因果链，分场篇幅仍在扩写。

本轮先读 [全稿一致性修订](coherence-review.md)，再读 [模糊预告、责任与后日谈](warning-and-aftermath.md)：22日晚分层听辨、居民疑点、故意隐瞒与十一月收尾已落成QS。

1. [世界观](worldbuilding.md)：时代、城市、社会生活、设施与空间关系；开头可作为面向玩家的介绍。
2. [人物](characters.md)：名称、外形、职业能力边界、动机、关系与人物弧线。
3. [时间通信与案件真相](mystery-logic.md)：作者用规则、来源分支、事故链、证据与漏洞问答。包含全部剧透。
4. [时间表](timeline.md)：现实日期、回声收发、源分支与实际行动的对照。
5. [完整大纲](story-outline.md)：序章至尾声，每章的具体事件、转折及结局。
6. [感情线](relationship-arc.md)：相互吸引的原因、主动选择、冲突与修复。
7. [序章分场](prologue.md)：可直接展开正文的场景安排与文风试写。
8. [写作与揭示节奏](writing-guide.md)：玩家每一阶段知道什么、叙述口吻和互动规则。
9. [美术设定](prompt-bible.md)与[素材清单](asset-manifest.md)：正式视觉需求，均未生成。
