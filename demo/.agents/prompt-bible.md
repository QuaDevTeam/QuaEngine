# 美术设定：初夏梅雨的青叶

状态：172cm的v7双主角样图已生成并由助手审阅；单人立绘与差分仍待制作，尚无正式素材接入游戏。人物名称、年龄、发型、衣服以 characters.md 为准。

## 统一画风

**明确的日本二次元galgame风格**：简洁而清楚的动画线稿，干净底色配两至三阶赛璐璐阴影；大而有神的动画眼睛、简化鼻口、成组发束与图形化高光。人物依角色约六至六点八头身，年龄通过体态、服装与表演区分，不用写实面孔表现“成年”。背景采用日本动画背景画的概括形状和选择性细节，与角色协调，不能像建筑效果图或照片。

用户已明确否决首张偏写实凛参考：不得再沿用其画风、写实五官、密集布料纹理或灰褐色调。禁止照片感皮肤、皮肤毛孔、厚涂写实、时装插画、3D体积感与油画式渲染。先检查新版双主角常服对照，再分别制作单人参考与差分；拒稿不能传给其他角色或CG。

环境有湿度和生活磨损：玻璃水痕、略旧的吸音板、纸箱、塑料伞、除湿机水箱。白天以暖白、浅蓝、灰绿为主，室内木色与暖灯；雨夜以低饱和蓝灰和少量室内暖色对照。

科技细节落在普通物件：电子站牌、便携录音屏、小型防水接头、港口自动搬运车。不要霓虹都市、到处悬浮界面、发光服装或巨大人工智能眼睛。

## 人物视觉锁定

以 [六人造型区分](character-visual-design.md) 为最新规格。`heroine-summer-v7`：凛25岁／163cm，清秀可爱、约6.4头身，蓝黑短发、雾蓝圆领T恤、深蓝轻薄直筒长裤及白色运动鞋。Mara24岁／172cm，约6.8头身，及腰灰棕长发、柔和稍长的脸型与舒缓琥珀眼，温柔从容、有年轻御姐气质；奶油黄微泡袖衬衫、米白及膝裙与平底鞋。Mara同地面比凛高9cm，不能用透视或高跟鞋制造差值。最新要求覆盖此前相同年龄感、头身与3cm身高差的限制。

两人默认服装都是六月的轻薄夏装，冷气与雨天按场景增加薄外搭。主角不再使用成熟职业装与幼小运动工装的反差。春香158cm、真由171cm、礼子167cm、由美153cm，分别以心形脸／背带裙、长矩形脸／实用夹克、菱形脸／薄西装直裙、丰满宽圆脸／宽松裙裤区别。

每人的基础参考从独立文本生成，不将其他角色的脸与身材作为编辑底图。禁止所有人同样的侧刘海、尖下巴、眼型、模特长腿、衬衫宽裤和摸耳动作；不能只改发色和衣服颜色。年轻主角呈现20多岁女性的清新感，配角各按真实年龄区别，不给所有人同一套成熟面部。

凛外勤加烟灰透明雨衣，Mara 外勤加珊瑚橙轻量雨衣；自然淋湿不变成透视服装。科研区劳动防护只在具有权限的场景出现，主角不穿危险作业装备来暗示能替代专业人员。

## 演出区别

- 日常 CG 要表现共同动作：扶纸袋、分监听、听录音。不要每张都画背对镜头看远景。
- 死亡回声 CG 使用仍然温暖的播音室、凛的手停在音量旋钮上、Mara 活生生站在画面另一侧；不要提前画尸体给玩家视觉误导。
- 告白在雨停后的开放观景台，二人面部与回应清晰；避免逆光把表情全吞掉。
- 暴雨素材沿用同一建筑与门窗位置。东堤中继站与灯塔是不同地点，危险不发生在告白处。
- 广播日期、录音来源、节目名称、台词由 UI 正常排字，图像模型不生成关键文字。

## 资产技术约束

背景／CG 为 16:9；场景遵循 1920×1080 逻辑舞台。主要人物和线索保持在安全区内。立绘完整保留头脚、手部、眼白，透明边缘需逐张检查。

表情差分共用发型、轮廓、服装、比例和光源。保留普通嘴角、视线、肩膀与手势差异；不要求每种情绪都大幅换姿势。工作耳麦可摘，但需记录在哪个场景摘下。

新生成时建立正式参考图后再扩展差分，不复用旧角色 PNG 来限制已获准重设计的服装。图像格式、抠图实现与模型选择需根据当时工具核验，不继承旧文档中矛盾的绿幕／白底与模型断言。
