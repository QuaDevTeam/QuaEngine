# 美术设定：初夏梅雨的青叶

状态：设计规格，正式素材尚未生成。人物名称、年龄、发型、衣服以 characters.md 为准。

## 统一画风

商业日系视觉小说动画风格，清晰线条与柔和背景绘景，成年人体态约六点五至七头身。环境有湿度和生活磨损：玻璃水痕、略旧的吸音板、纸箱、塑料伞、除湿机水箱。白天以暖白、浅蓝、灰绿为主，室内木色与暖灯；雨夜以低饱和蓝灰和少量室内暖色对照。

科技细节落在普通物件：电子站牌、便携录音屏、小型防水接头、港口自动搬运车。不要霓虹都市、到处悬浮界面、发光服装或巨大人工智能眼睛。

## 演出区别

- 日常 CG 要表现共同动作：扶纸袋、分监听、听录音。不要每张都画背对镜头看远景。
- 死亡回声 CG 使用仍然温暖的播音室、凛的手停在音量旋钮上、Mara 活生生站在画面另一侧；不要提前画尸体给玩家视觉误导。
- 告白在雨停后的开放观景台，二人面部与回应清晰；避免逆光把表情全吞掉。
- 暴雨素材沿用同一建筑与门窗位置。东堤中继站与灯塔是不同地点，危险不发生在告白处。
- 广播日期、录音来源、节目名称、台词由 UI 正常排字，图像模型不生成关键文字。

## 资产技术约束

背景／CG 为 16:9；场景遵循 1920×1080 逻辑舞台。主要人物和线索保持在安全区内。立绘完整保留头脚、手部、眼白，透明边缘需逐张检查。

表情差分共用发型、轮廓、服装、比例和光源。保留普通嘴角、视线、肩膀与手势差异；不要求每种情绪都大幅换姿势。工作耳麦可摘，但需记录在哪个场景摘下。

新生成时建立正式参考图后再扩展差分，不复用旧角色 PNG 来限制已获准重设计的服装。图像格式、抠图实现与模型选择需根据当时工具核验，不继承旧文档中矛盾的绿幕／白底与模型断言。
