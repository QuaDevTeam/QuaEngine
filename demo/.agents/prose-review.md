# 文学复核与QS润色

2026-09-08。已在全部14个QS模块中修改79处段落。此轮不扩展场卡、分支或科学规则，重点是已有首稿的阅读感。实际篇幅以manuscript-status和manuscript-count为准，删去重复解释不视为损失必要剧情。

## 本轮判断与处理

1. **人物做完事，旁白又替她总结。** 如“没有得到已经和好的保证，也没有索取”“没有借此安慰我”“她没有等别人安排下一件事”，读起来像作者在解释人物弧线。改成手碰到证件绳、豆腐搁在勺里、手机上的一句消息等当下可见动作，让前后语境承载意思。不是机械禁用“没有”，真正的回避、未知与被隐瞒的内容仍要写清。
2. **工作对白容易写成审稿答辩。** 删除“听众没有参加我们的试验”等抽象说理，改成“有人会照着那个时间出门”。真由解释接口、校时和音频用途时仍保留技术条件，但用能指到纸上、设备上的具体说法；春香讲自己问到的消息来源，由美负责叫停、催回执，不能人人同一种口吻。
3. **凛的内心过早把自己分析明白。** 隐瞒时保留她“等安全了再说”的自我说服；听到完整死讯后，留下她仍没划掉的“也许是在报告现场”。修复信任时少讲“不能把害怕变成催促”，让她打出“快点”、看一眼仍亮着灯的转播车、删掉两个字。错误、改口与情绪仍由她亲自承担。
4. **动作重复与视角越界。** 合并连续戴耳机、划走邮件等重复起手；Mara看帽子价签改为没念出价格，后面的“我还没说”才接得上。真由在电话另一端时，凛只听翻纸声、看收到的附件；礼子未出口的辩解不由凛代念。游船场明确是船舱外的平台。
5. **亲密场过分工整。** 保留明确互相告白、同意与回应，两个吻改成不同反应：第一次忘记闭眼，第二次攥住衣角，走下台阶再牵手。Mara也有自己的局促，凛有主动回应；不将角色改成恋爱导师。
6. **后日谈接近一页处理报告。** 十一月借两人一起翻材料，区分礼子与真由的后续岗位、审批限制与公司责任；赔付、居民睡眠和排水、研究退出、档案归属仍逐项收尾。九月电话以收衣服后的晚安结束，不与十一月的末句完整重复。
