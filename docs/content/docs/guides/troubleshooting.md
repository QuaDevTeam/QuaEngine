## 预览空白或一直停在载入中

先打开终端和浏览器控制台，确认是不是有启动异常被界面盖住了。接着检查初始场景有没有真正跑起来、资源根目录路径对不对，以及渲染器是否已经订阅到引擎投影。如果开发期一切正常、只有生产构建出问题，重点排查构建出的资源索引和 CSP 响应头，通常不需要去改剧本文本。

## 装饰器无法识别

确认对应功能包提供了 `./script-compiler` 入口，而且已经被当前项目的编译配置正确发现。再核对一下装饰器拼写、参数格式，以及装饰器与正文之间有没有误插空行。在运行时调用 `.use(new Plugin())`，并不会自动让编译器在构建期识别该插件的装饰器。

## 选择后没有跳到预期剧情

检查选项后面写的目标类型以及注册情况。`- 去海边 -> nodeName` 只是发起跳转请求，不会自动帮你创建节点；不写目标的选项本来就会在选中后顺着下一行继续执行。如果是跳往动态包里的节点，还要确认那个 QPK 已经激活，且节点元数据里保留了正确的包来源。

## 音乐没有声音

在 Web 上先点击一下页面，排查是不是浏览器拦截了自动播放导致 `AudioContext` 还没解锁，然后再依次检查音频编码、包内路径、总线增益和当前音频意图。如果是 Cocos、Godot 或 Native 平台，请直接对照各自宿主的音频后端能力排查，不要套用浏览器的解锁逻辑。

## 手机画面四周有黑边

逻辑舞台默认按固定比例等比缩放，画面两边或上下留出黑边属于正常保护机制，不要靠裁切画面或者改写逻辑宽度来硬撑满屏。如果需要针对手机做竖屏构图，请切换到 `portrait` 预设并重新安排安全区域内的布局。

## Rust/wgpu Native 升级后加载不了资源包

检查 `target-bundle-manifest.json` 里的 `javascriptcore` 标识、`jscVersion`、签名宿主和模块元数据是不是和当前二进制一致。升级后请清理并重新生成受影响的构建产物，不要再试图接回已经移除的 QuickJS 路径。

Godot 使用的是另一套独立的 GDExtension + QuickJS 宿主，遇到问题时请核对当前操作系统和架构对应的动态库、静态 QPK 哈希以及 `target-bundle-manifest.json`，不要拿 Native 的 JSC 配置去套。项目生成和已知差异见[Godot 独立项目](/docs/platforms/godot)。

## 安装依赖时被安全策略拦截

遇到报错先保留完整的错误输出和具体包版本，对照注册表来源和现有锁文件排查，不要为了省事直接关掉安全策略。另外，文档站自己有独立的锁文件和工程配置，预览文档不需要重新安装主仓库的全部游戏依赖。

## 如何提交一个容易复现的问题

提 issue 时请附上操作系统、Node/pnpm 版本、目标平台、当前 commit 哈希、能复现问题的最小剧本或目录结构，以及完整的复现步骤和原始报错。上传日志或工程片段前，记得清理掉 API 密钥、私有剧本正文和未授权分发的素材文件。
