## 打开与配置

从左侧活动栏进入 Novel Writer，整个编辑区域切到写作工作区。用资源管理器图标或 Ctrl/Cmd+Shift+E 返回剧本工作区，两边的草稿保留。写作中的 Ctrl/Cmd+S 保存稿件，Ctrl/Cmd+, 打开写作设置。

先配置 DeepSeek；需要外部资料搜索时配置 Tavily。模型调用需要网络和提供商额度，提交任务前确认要发送的项目设定与正文范围。Novel Writer 是编辑器工具，不会作为游戏运行时插件发给玩家。

## 从项目或 QuaScript 建立任务

创建项目关联任务，说明目标、篇幅、背景约束和可改动范围。已有世界观、人物与大纲会作为输入保留，缺失设定可通过「关联并补齐设定」补充，不会静默覆盖原有设定。

「从 QS 改写」读取 Monaco 当前缓冲区与选区，包括未保存正文。任务保存源文件、范围与版本快照；源文档后来改变时需重新捕获或处理冲突。

阶段审核与大纲检查仍然保留，输入已有设定不会跳过后续审查。流式预览只是进行中的文字；最终结构化结果保存后才成为可操作产物。

## 审核、重生成与回写

先阅读产物，添加修改要求或重新生成对应阶段，再检查稿件/差异预览。回写支持新建 QS、追加到原文件或智能替换原位置。智能回写结合源码锚点与变量计划，保留 TypeScript、演出、选择和故事元数据，并检查实际编译诊断。

应用会核对项目、缓冲区、磁盘版本和修改范围。结果成为可撤销 Monaco 草稿，正常保存后才进入磁盘、索引与预览；不会直接覆盖游戏状态。新建场景仍需按项目入口接入。

编译通过不能证明动机、节奏或每条运行分支正确。实际阅读并走完受影响的选择、跳转和恢复；离线/mock 检查不能证明真实模型的写作质量。

## 保存、继续与回收站

默认数据目录为 `~/.quaengine/novel-writer`，工作流用追加 JSONL 与快照恢复；配置的应用数据根可覆盖默认位置。隐藏写作视图不等于取消生成，关闭时会保护未保存内容和运行任务。已保存产物/检查点可在下次打开后继续。

普通删除移动到应用回收站，可恢复；重置任务清除生成产物与历史并保留基础输入，需显式操作。不要用删除数据目录代替界面中的重置或取消。

## 导出

ZIP 包含 `README.md`、`project.json`、`manifest.json`、`combined.md` 与 `artifacts/` 中的 Markdown/JSON。当前导出包含 `approved` 和 `draft` 产物，排除 `needs_review` 与 `rejected`；**草稿导出不表示已审核通过**。

原始工具事件与提供商凭据不作为导出文件，但项目元数据、任务输入和正文仍可能含私有内容。分享前检查归档，不把 ZIP 当成完整事件日志/凭据/运行环境备份。
