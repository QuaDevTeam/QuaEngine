## 定位

Novel Writer 是编辑器内置的本地写作应用，源码位于 `packages/editor/novel-writer`。它调用已配置的 DeepSeek 服务组织需求、世界观、人物、大纲、场景写作与审校；Tavily 在需要外部资料时提供搜索。

它不属于游戏运行时，不会在玩家端作为 QPK 插件运行。使用前先在设置里完成提供商配置。真实模型调用需要网络和提供商额度；离线测试不能证明实际写作质量。

## 从项目建立任务

打开写作视图，建立与当前项目关联的任务，说明目标、篇幅与要保留的设定。可以从现有 QuaScript 选区建立改写任务，带上原始正文与项目上下文。

已有世界观、人物与大纲作为任务输入保留；额外修改指令应明确指出哪些部分可以调整。阶段审核与大纲检查仍然存在，输入材料并不会让后续步骤自动跳过。

## 审核与应用

生成中的内容先以预览显示，最终结构化结果保存后才成为可审核产物。检查内容、批注或重新生成单个阶段，再预览应用到 QuaScript 的结果。

应用前会核对项目、原始缓冲区、磁盘版本和修改范围；发生变化需要重新捕获源文档。更新以 Monaco 可撤销草稿进入编辑器，仍经过正常保存和冲突检查。保留变量、分支与编译语义比直接覆盖整份源文件更重要。

## 本地存储与恢复

任务和产物保存在 `~/.quaengine/novel-writer`。工作流事件使用追加 JSONL 与快照恢复。普通删除移动到回收站；重置任务会清除生成产物与历史，并保留任务基础输入，需要用户明确操作。

导出只包含已完成的可导出产物，不应包含凭据、原始工具记录或未通过审核的内容。具体行为以当前编辑器 UI 和源码为准。

## 质量检查

静态检查能发现语法和部分契约问题，不能判断角色动机、叙事节奏与所有运行期分支是否正确。请实际阅读生成段落，再在预览中走完受影响选择、跳转和恢复路径。
