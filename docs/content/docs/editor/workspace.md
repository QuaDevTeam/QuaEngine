## 侧栏与视图布局

左侧的资源管理器、搜索、源代码管理与故事大纲组成了固定的导航区，通过最左边的活动栏切换。这四个视图不能拖走、拆分或合并；不过侧栏的分隔线支持鼠标拖动、方向键微调和双击恢复默认宽度。

代码编辑器、预览面板、语句属性与各类工具面板则可以自由停靠。把标签拖到面板分组中央可以合并，拖到边缘可以拆分，标签右键菜单或 `Shift+F10` 也能执行同样的操作。关掉某个标签只是把它暂时收起，随时可以从标题栏右上角的布局图标打开「视图」菜单，按中文名、英文 ID 或分类搜出来重新打开。执行「重置布局」会保留你所有的文档草稿和面板状态。

## 设置与外观

按 `Ctrl/Cmd+,` 或点击左下角的齿轮图标即可打开设置。设置页支持按分类浏览、关键词搜索、只看已修改项，以及单项恢复或全部重置。

| 类别 | 常用选项 |
| --- | --- |
| 外观 | Qua / 石墨配色主题，跟随系统 / 浅色 / 深色模式 |
| 代码编辑器 | 字体、字号、行高、缩进、自动折行、行号、缩略图（minimap）、保存时格式化 |
| 终端 | 字号、历史回滚行数、光标闪烁 |
| 工作区 | 控件紧凑度、减少动态效果、下次启动时恢复布局 |

设置保存在当前编辑器的用户配置中。切换外观主题会即时刷新工作台、Monaco、终端和官方插件面板，但不会篡改游戏本身的美术画面或 Novel Writer 的视觉风格。重启时恢复布局也不会重新拉起上次的 shell 进程，布局记忆也不能替代未保存文档的崩溃恢复。

## 项目搜索

按 `Ctrl/Cmd+Shift+F` 打开项目全文搜索，支持区分大小写、全词匹配、Rust 正则表达式，以及包含/排除 glob 过滤（多个 glob 用英文逗号隔开，例如 `**/*.qs, **/*.ts`）。搜索只扫描磁盘上的已保存文件，不包含未保存草稿；如果命中了文件大小、结果数或耗时上限，请加上路径过滤缩小范围。

故事大纲则负责从已索引的场景与节点直接跳回源码位置，它只是导航工具，不会替项目新建分支目的地或改动游戏进度。

## 集成终端

按 `Ctrl+反引号` 显示或隐藏终端，按 `Ctrl+Shift+反引号` 新建终端会话。终端默认在当前项目根目录启动（未打开项目时在用户主目录）。里面运行的是真实的系统 shell，可以切换多个会话、清空屏幕或终止进程。

终端获得焦点时，`Ctrl+C` 等快捷键会直接发给 shell。复制粘贴在 macOS 上使用 `Command+C/V`，其他系统使用 `Ctrl+Shift+C/V`。切换项目或关闭编辑器时，受管理的终端会话和子进程会被一并清理（主动脱离进程树的后台 daemon 不受此限制）。需要注意，终端输出不会跨重启保留，而且终端拥有当前系统用户的完整权限，不是受限沙箱。

## Git 更改与分支

源代码管理面板会将合并冲突、已暂存更改和工作区修改分组列出，支持树形或列表视图、只读差异对比以及行内暂存和取消暂存。在提交说明输入框旁点击提交按钮（或按 `Ctrl/Cmd+Enter`）即可提交已暂存的文件。记得先保存编辑器草稿，Git diff 只对比磁盘上的文件。

切换分支时如果有未保存的文档，编辑器会询问你是「保存全部」「保留草稿」还是「取消」。磁盘上的未暂存修改由正常的 `git switch` 决定能否顺利带过去；如果你选择保留草稿，而目标分支恰好改了同一份文件，后续保存时依然需要走一遍冲突对比流程。目前面板不提供自动 stash、强制切换、push 或 pull，这些操作可以在集成终端里按团队习惯执行。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd+P` | 快速打开文件 |
| `Ctrl/Cmd+Shift+E` / `Ctrl/Cmd+Shift+F` | 切到资源管理器 / 项目全文搜索 |
| `Ctrl/Cmd+S` / `Ctrl/Cmd+Shift+S` | 保存当前文档 / 保存全部 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换文件标签页 |
| `Ctrl/Cmd+J` | 显示或隐藏底部面板 |
| `Ctrl/Cmd+Shift+P` 或 `F1` | 打开 Monaco 命令面板 |
| `F5` / `Shift+F5` | 启动或重启预览 / 停止预览 |
| `F10` | 预览推进一步 |
| `Ctrl/Cmd+Alt+Enter` | 从源码光标处定位预览 |
| `Ctrl/Cmd+Shift+B` | 打开生产打包 |

部分快捷键可能会受当前焦点区域、集成终端或系统输入法影响；把鼠标悬停在界面按钮上通常就能看到对应的提示快捷键。接下来可以看[预览、定位与调试](/docs/editor/preview)。
