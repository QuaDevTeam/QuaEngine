## 侧栏与视图布局

左侧资源管理器、搜索、源代码管理和故事大纲是固定导航区，通过活动栏切换。它们不能拖拽、拆分或合并；侧栏分隔线支持拖动、方向键调整与双击重置。

代码、预览、语句属性及工具面板可停靠。拖动标签到分组中央合并，到边缘拆分；标签右键或 Shift+F10 提供对应操作。关闭标签只收起视图，可从标题栏布局图标打开「视图」菜单，按名称、英文 ID 或类别查找并重新打开。重置布局保留文档草稿和功能实例。

## 设置与外观

Ctrl/Cmd+, 或左下角齿轮打开设置。支持分类、搜索、仅显示已修改项、单项恢复与整体恢复。

| 类别 | 常用设置 |
| --- | --- |
| 外观 | Qua / 石墨主题，跟随系统 / 浅色 / 深色 |
| 代码编辑器 | 字体、字号、行高、缩进、换行、行号、minimap、保存时格式化 |
| 终端 | 字号、滚动记录、光标闪烁 |
| 工作区 | 控件密度、减少动态效果、下次启动恢复布局 |

设置保存在当前编辑器用户配置。主题更新工作台、Monaco、终端和官方插件，不改写游戏画面或 Novel Writer 的外观。布局恢复不会重启旧 shell 进程；编辑器布局偏好也不等于全部未保存文档的崩溃恢复。

## 项目搜索

Ctrl/Cmd+Shift+F 打开全文搜索，支持大小写、全字、Rust regex 正则与包含/排除 glob；多个 glob 以逗号分隔，例如 `**/*.qs, **/*.ts`。结果读取磁盘，不搜索未保存草稿。达到结果、文件大小或时间上限时，请缩小范围。

故事大纲从已索引的场景与故事节点定位源码，不会替项目创建分支目的地或修改游戏进度。

## 集成终端

Ctrl+反引号显示/隐藏终端，Ctrl+Shift+反引号新建会话。初始目录为当前项目；未打开项目时为用户目录。终端运行真实 shell，可切换会话、清空显示或终止进程。

终端聚焦时 Ctrl+C 等按键交给 shell。复制粘贴使用 macOS Command+C/V，其他平台 Ctrl+Shift+C/V。切换项目或退出时会结束受管会话与子进程；自行脱离的 daemon 不在此保证内。会话和输出不跨编辑器重启恢复，终端也不是项目目录沙箱。

## Git 更改与分支

源代码管理分组显示冲突、已暂存和工作区更改，支持树/列表、文件差异、暂存/取消暂存。提交说明旁的提交按钮或 Ctrl/Cmd+Enter 提交已暂存内容；先保存文件，Git diff 不包含未保存的编辑器草稿。

分支切换可选择保存全部、保留草稿或取消。正常 `git switch` 决定磁盘修改是否可保留；目标分支改了同一文件时，保留草稿后仍可能需要解决保存冲突。当前不提供自动 stash、强制切换、push 或 pull，可在终端按项目流程处理。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl/Cmd+P | 快速打开 |
| Ctrl/Cmd+Shift+E / Ctrl/Cmd+Shift+F | 资源管理器 / 项目搜索 |
| Ctrl/Cmd+S / Ctrl/Cmd+Shift+S | 保存当前 / 全部 |
| Ctrl+Tab / Ctrl+Shift+Tab | 切换文件标签 |
| Ctrl/Cmd+J | 显示/隐藏底部面板 |
| Ctrl/Cmd+Shift+P 或 F1 | Monaco 命令面板 |
| F5 / Shift+F5 | 运行或重启 / 停止预览 |
| F10 | 推进一步 |
| Ctrl/Cmd+Alt+Enter | 从源码光标定位预览 |
| Ctrl/Cmd+Shift+B | 打开生产打包 |

快捷键受焦点、终端与输入法影响；控件的悬浮提示显示对应操作。继续看[预览与调试](/docs/editor/preview)。
