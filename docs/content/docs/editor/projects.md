## 创建或打开项目

点击「文件 → 新建项目」，选定父目录并填好项目名称，就可以创建常规的 Vue / QuaScript 游戏项目或插件项目。编辑器会在父目录下新建一个子目录，不会覆盖同名文件夹。模板自带源码、配置、README 以及 `vendor/quajs` 里的本地 SDK 压缩包，生成后的项目可以自由移到仓库之外。

打开已有游戏时，请选择同时包含 `package.json` 和 `qua.project.yaml`（或 `.yml` / `.json`）的目录。如果要发布插件，也可以直接打开包含 `quajs.extension` 声明的插件包目录，不需要伪造一份游戏配置；插件项目只显示构建流程，不会展示游戏预览区域。

## 准备运行环境

打开项目或启动预览时，工作区会自动检测 Node.js、npm/pnpm、项目依赖以及所需的 Rust 工具链。如果缺少工具，编辑器会把它们下载到用户数据目录下的 `runtimes` 文件夹中，并在界面上显示进度、日志、取消与重试按钮，不会改动你的全局 shell 环境。

不过，像系统 SDK 和链接器这类基础环境仍需自行在操作系统里装好——例如 macOS 源码构建需要 Command Line Tools 和对应版本的 Electron Node-API 头文件。下载第三方依赖时需要连接网络，请求同样会遵循编辑器读取到的系统代理配置。

## 找到与修改文件

| 文件或目录 | 用途 |
| --- | --- |
| `src/game/scenes/*.qs` | 剧情正文与演出指令 |
| `src/game/bootstrap.ts` | 引擎、插件与渲染器初始化接线 |
| `qua.project.*` | 项目身份、图标与发布目标配置 |
| `assets/` | 背景、立绘、字体、音频等原始素材 |
| `*.animation.json` | 可视化数值动画源文件 |

按 `Ctrl/Cmd+P` 可以模糊搜索并快速打开文件，支持加上 `:行:列` 直接跳转。资源管理器支持新建、重命名、剪切、复制、粘贴以及删除到系统废纸篓。需要注意，重命名或移动文件时会保留已打开标签页的草稿与撤销栈，但不会自动修改剧本里的 import 路径或资源引用，移动后记得顺手看一眼「问题」面板。

复制操作读取的是磁盘上已保存的内容。删除文件前会弹窗确认，并保留编辑器里尚未保存的缓冲区；目前暂不提供文件系统的撤销操作，也没有针对已删除文件的“另存为”恢复入口。

## 导入与检查资源

在底部的 Assets Browser 里选定一个资源文件夹，点击「导入」即可把本地媒体、字体或资源包复制进去（「全部资源」对应项目根目录）。遇到同名文件时默认跳过而不覆盖。界面支持按名称、路径和类型筛选，按名称、大小或修改时间排序，并支持网格和列表两种视图。

选中图片后可以预览画面并查看格式、原始像素尺寸、文件大小和透明通道；音频与视频支持就地播放试听。字体和 QPK/ZIP 目前只展示基础文件信息，暂不提供字体排版预览或包内文件浏览。另外，把素材导入目录不会替代 Quack 资源打包，也不会自动往剧本里插入引用。

## 保存与冲突

按 `Ctrl/Cmd+S` 保存当前文档，`Ctrl/Cmd+Shift+S` 保存全部已修改文档。无论是语句属性面板、角色面板、动画面板还是 AI 回写产生的源码草稿，都统一走这套保存流程。

当磁盘上的文件被外部程序修改时：如果编辑器里没有未保存草稿，内容会自动同步；如果有未保存草稿，编辑器会保留你的草稿并提示冲突。点击「比较差异」查看变化、整理好本地内容后，选择「保留本地并保存」即可写回磁盘——保存前编辑器会再次核对磁盘版本号，防止覆盖你在比对之后新出现的外部改动。若决定放弃草稿，点击「载入磁盘版本」会二次确认后重新读取磁盘文件。

启动预览、从源码定位以及执行生产打包前都需要先完成保存，一旦保存失败或遇到未解决的冲突，对应操作会中止。此外，项目索引与全文搜索主要读取磁盘文件，所以未保存草稿上的实时诊断并不代表搜索结果也已经同步更新。

## 项目索引

文件监听器会合并短时间内的批量变动，再统一刷新文件树、角色列表、资源、故事节点和诊断信息。为了避免卡顿，索引对文件数量、目录深度和遍历范围做了限制，符号链接、隐藏目录、`node_modules` 和生成目录都不会被当成普通源码扫描。收到超出上限的提示时，可以缩小项目范围或手动点击「刷新项目」。索引检查失败时，已打开的草稿会原封不动地保留下来。
