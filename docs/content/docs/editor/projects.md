## 创建或打开项目

选择「文件 → 新建项目」，填写父目录与项目名，创建 Vue / QuaScript 游戏或插件项目。编辑器在父目录下新建子目录，不覆盖已有目录。模板附带源码、配置、README 和 `vendor/quajs` SDK 压缩包，项目可以移出 QuaEngine 源码仓库。

打开已有游戏时，选择含 `package.json` 和 `qua.project.yaml`、`.yml` 或 `.json` 的目录。插件发布可以直接打开含 `quajs.extension` 声明的包目录，无需伪造游戏配置；插件项目使用构建流程，不显示游戏预览。

## 准备运行环境

打开项目或启动预览时，工作区检查 Node.js、npm/pnpm、项目依赖和所需 Rust 工具链。缺失工具下载到编辑器用户数据的 `runtimes` 目录，进度、日志、取消和重试显示在界面中，不修改全局 shell 配置。

系统 SDK 与链接器仍需系统安装。macOS 源码构建需要 Command Line Tools 与正确的 Electron Node-API 头文件。第三方依赖下载需要网络，包管理器请求遵循编辑器的系统代理配置。

## 找到与修改文件

| 文件 | 通常用途 |
| --- | --- |
| `src/game/scenes/*.qs` | 剧情正文与演出 |
| `src/game/bootstrap.ts` | 引擎、插件与渲染器接线 |
| `qua.project.*` | 项目身份、图标与构建目标 |
| `assets/` | 背景、立绘、字体、音频等素材 |
| `*.animation.json` | 可视化数值动画源文件 |

Ctrl/Cmd+P 快速打开文件，支持模糊路径与 `:行:列`。资源管理器可新建、重命名、剪切、复制、粘贴及删除到系统废纸篓。重命名/移动保留打开文档的草稿与撤销历史，但不会自动重写导入或资源引用；完成后检查「问题」面板。

复制读取磁盘内容。删除需要确认，未保存缓冲区仍会保留；当前没有文件系统操作撤销或删除文件的“另存为”恢复流程。

## 导入与检查资源

在 Assets Browser 选择资源文件夹，点击「导入」复制媒体、字体或资源包；「全部资源」对应项目根目录，同名文件跳过而不覆盖。可筛选名称、路径与类型，按名称/大小/修改时间排序，切换网格与列表。

图片支持预览与格式、原始像素尺寸、大小和透明通道检查，音视频支持本地播放。字体和 QPK/ZIP 目前仅显示文件信息，不提供字体排版预览或包内浏览。导入不会代替项目的 Quack 资源构建，也不自动创建剧情引用。

## 保存与冲突

Ctrl/Cmd+S 保存当前文档，Ctrl/Cmd+Shift+S 保存全部。语句、角色、动画和 AI 编辑产生的源码草稿都沿用正常保存路径。

外部修改在无本地草稿时自动同步；有草稿时先保留并报告冲突。选择「比较差异」检查后，可继续整理本地内容，再「保留本地并保存」。保存会重新核对磁盘版本，不能覆盖比较之后出现的新修改。「载入磁盘版本」会在丢弃草稿前确认。

启动预览、源码定位和生产打包需要先保存；保存失败或冲突会中止操作。项目索引与全文搜索主要读取磁盘，未保存文本的实时诊断不代表搜索结果已经更新。

## 项目索引

文件监听合并变化后刷新文件、角色、资源、故事与诊断。索引有文件数、深度与目录上限，符号链接、隐藏目录和依赖/生成目录不会按普通源文件遍历。出现上限或监听提示时缩小项目范围，或使用「刷新项目」。检查失败不会清空当前草稿。
