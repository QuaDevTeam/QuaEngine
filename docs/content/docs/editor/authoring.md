## 编写与检查剧本

从[第一幕](/docs/getting-started/first-story)的完整 `.qs` 文件开始。Monaco 提供高亮、Ctrl+Space 补全、悬浮说明、F12 定义跳转、Shift+Alt+F 格式化与 Ctrl/Cmd+Shift+Space 参数提示。定义跳转限于当前项目可编辑源文件。

不同角色有稳定的对白颜色，旁白、注释、选项和 TypeScript 插值保留对应语法颜色。颜色只是阅读辅助，不决定角色注册或运行时身份。

## 用语句属性编辑

在 `.qs` 文档工具栏打开「语句属性」，底部面板会跟随光标；也可用语句选择器和前后按钮定位。当前工作流是 Monaco 加独立属性面板，旧的代码/分栏/可视化模式切换已移除。

可修改台词、说话者、已有指令中的字符串/数字/开关及嵌套对象参数，并添加背景、清除背景、语音、BGM、角色登退场、立绘、表情和位置指令。角色与资源字段提供项目候选。

没有背景指令代表沿用此前状态；要清除背景必须添加显式清除指令。表单只表示当前语句，不推断整个场景执行后的背景或角色位置。复杂表达式、数组与选择分支回到源码编辑；语法错误时表单暂停，修复后恢复。

## 撤销与保存

表单输入成为同一份 Monaco 可撤销草稿，代码修改也会更新表单。Ctrl/Cmd+Z 撤销，正常保存后才写入磁盘并刷新项目索引。切换标签保留草稿；磁盘冲突按[项目与文件](/docs/editor/projects#保存与冲突)处理。

角色与动画面板另有“应用到源文件”步骤。应用创建源码草稿，随后仍需保存；不要把面板本地草稿、Monaco 草稿和磁盘文件当作同一层。

## 诊断和导航

「问题」汇总已索引 `.qs` 和项目 TypeScript 的配置、语法与类型诊断，点击定位行列。当前打开文件的未保存文本有实时诊断；其他文件主要读取磁盘。

项目安装了 ESLint 并包含配置时，TS/JS 文件还会按项目自己的解析器、规则和忽略项检查。缺少配置时跳过，依赖或配置错误会提示；编辑器不自动运行修复写盘。

移动/重命名文件、角色 ID 或资源时，不会自动重写故事引用。检查问题列表，并在实际预览中走完选择、跳转与恢复。

## 在运行画面中修改

Web 项目接入开发预览协议后，可在「场景调试」启用「拾取属性」。点击背景或角色定位其 QS 来源；字面单行对白可进入内联文本编辑，生成普通源码草稿。插值、富文本、多行文本或过期来源改用源码入口。

这项能力仅限 Web 开发预览，保存后沿用正常重载；它不直接修改渲染器里的游戏状态，也不提供任意时间轴拖拽恢复。继续看[预览与调试](/docs/editor/preview)。
