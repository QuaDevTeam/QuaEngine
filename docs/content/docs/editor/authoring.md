## 编写与检查剧本

可以参考[写下第一幕](/docs/getting-started/first-story)里的完整 `.qs` 文件来起步。Monaco 编辑器自带语法高亮、`Ctrl+Space` 智能补全、悬浮文档提示、`F12` 跳转定义、`Shift+Alt+F` 格式化以及 `Ctrl/Cmd+Shift+Space` 参数提示（其中定义跳转只打开当前项目内可编辑的源文件）。

不同说话角色会自动分到固定的对白配色，旁白、注释、选项和 TypeScript 插值也各自保留清晰的语法颜色。这里的颜色纯属阅读辅助，并不代表角色注册或影响运行时的角色身份。

## 用语句属性编辑

打开 `.qs` 文件后，点击文档工具栏上的「语句属性」，底部面板就会跟随着源码光标联动；也可以直接用面板里的语句选择器和前后按钮来切换语句。现在的工作流统一采用「Monaco + 独立属性面板」，早期的代码/分栏/可视化三模式切换已经移除。

在属性面板里，你可以修改台词正文、说话角色、已有演出指令中的字符串/数字/开关和嵌套对象字段，也可以直接添加背景、清除背景、语音、BGM、角色登退场、立绘、表情和位置指令。角色和资源下拉框会自动列出项目里的可用候选。

如果没有写背景指令，代表沿用上一句的背景状态；要撤掉背景必须显式加一条清除背景指令。属性表单只负责描述当前这一句本身，不会帮你推演整场戏跑到这一步后的累积背景或人物位置。遇到复杂表达式、数组或分支选择时，直接回到源码里写即可；当文件里存在语法错误时，表单会暂时停用，修好错误后自动恢复。

## 撤销与保存

在语句属性表单里做的每一项修改，都会直接同步进同一份可撤销的 Monaco 草稿里，反过来改代码也会实时刷新表单。按 `Ctrl/Cmd+Z` 可以正常撤销，只有点击保存后改动才会写回磁盘并刷新项目索引。切换标签页不会丢失草稿，遇到磁盘外部改动时按[保存与冲突](/docs/editor/projects#保存与冲突)解决。

另外，角色浏览器与动画编辑器有单独的「应用到源文件」步骤：点击应用后只会生成一份等待保存的源码草稿，之后依然需要手动保存。请把面板里的本地草稿、Monaco 里的源码草稿以及磁盘上的文件看作三个独立层次。

## 诊断和导航

底部的「问题」面板汇总了项目内已索引 `.qs` 文件和 TypeScript 配置、语法及类型错误，点击条目就能直接定位到对应的行和列。当前打开且有未保存修改的文档会实时刷新诊断，其余文件主要基于磁盘内容检查。

如果你的项目安装了 ESLint 并配好了规则，编辑器还会自动按项目自己的解析器、规则和忽略配置检查 TS/JS 文件；没配 ESLint 时则跳过，遇到依赖缺失或配置错误会在面板提示。编辑器不会在后台擅自运行自动修复写盘。

顺带一提，移动或重命名文件、角色 ID 或资源路径时，编译器不会自动重写剧本里的引用。调整完结构后记得看一眼「问题」面板，并在预览里把相关的选择、跳转与读档流程跑一遍。

## 在运行画面中修改

Web 项目接入开发预览协议后，可以在底部的「场景调试」面板启用「拾取属性」。开启后在游戏画面里点击背景或立绘，就能直接跳到设置它的 QuaScript 语句；点击普通的单行纯文本对白，还可以就地内联改字，改完同样生成一份正常的源码草稿。遇到带 `${...}` 插值、富文本、多行对白或源码已经过期的句子，则会自动引导你回源码编辑。

这项能力仅在 Web 开发预览下可用，保存后按正常热重载生效；它不会绕过引擎去直接篡改渲染器内部状态，也不支持把整个剧情当成视频时间轴那样随意拖拽回放。继续阅读[预览、定位与调试](/docs/editor/preview)。
