## 运行与切换目标

在预览面板的工具栏里选择 Web 或 Native，按 `F5` 启动或重启预览，按 `Shift+F5` 停止。启动前工作区会自动保存文档并核查依赖，遇到保存冲突会中止启动。Web 预览调用项目的 `dev:web`（或 `dev`）脚本，Native 预览调用 `dev:native`；切换目标时会先关掉旧的预览后端，当前运行中的游戏状态不会跨端迁移。

Native 图层内嵌目前仅支持 macOS，需要预先装好 Rust、系统工具链并在项目里接入 Editor preview 协议。目前嵌入层主要支持指针点击交互，键盘、IME 输入法、滚轮与独立的视口尺寸调整还在完善中。Windows 和 Linux 上选择 Native 会直接提示不支持，不会降级成截图轮询。

至于 Cocos 和 Godot，它们使用独立生成工程的命令行工具链运行，说明见[平台指南](/docs/platforms)。

## 到光标、单步与重载

把光标停在某句对白或选项上，点击工具栏的「到光标」或按 `Ctrl/Cmd+Alt+Enter`（也可以右键选择「运行到此行」），编辑器会先保存文件，再直接把预览定位到编译器对应的步骤位置。按 `F10` 可以单步推进一步，如果中途遇到分支选项，需要你在画面上实际点击选择后才能继续。

这项功能依赖项目注册一个可恢复的基线状态和脚本工厂。定位时，引擎会先回到基线，再从头顺序执行目标 `.qs` 文件到光标那一行——它不会凭空猜测前面几章选过哪些分支变量。如果当前场景强依赖前置章节状态，请在项目里准备好对应的开发基线。

编辑并保存 `.qs` 后，预览会自动重载并尝试停留在原来的步骤位置；如果原步骤被删掉或无法匹配，就会从该文件开头重放；如果整个文件被删除，则会退回项目初始启动界面。Web 端通过刷新页面更新，Native 端则需要重新打包 JavaScriptCore/QPK 并重启渲染进程，所以耗时会有差异；改动了引擎核心包或 Rust 源码后，仍需正常重新构建。

## 独立窗口与静音

工具栏上的「独立窗口」、全屏和重新嵌回功能都会完整保留当前的游戏会话；直接关掉独立窗口会自动嵌回工作区，全屏模式下按 `Escape` 退出。扬声器按钮可以一键静音预览画面——这项静音状态在本次编辑器运行期间会跨重启、目标切换和热重载一直保持，且不会去篡改游戏设置里的音量或音频播放进度。

## Inspector 与场景调试

底部的 Inspector 面板可以只读查看 Web DOM 或 Native QUI 的元素树、属性、坐标尺寸与计算样式，支持关键字筛选、折叠展开、键盘导航与手动刷新（它定位为轻量结构检查器，不是完整的 Chrome DevTools 或样式编辑器）。

针对 Web 目标，「场景调试」面板会记录已经跑过的对白轨迹以及 voice、BGM、SFX 和 ambient 的音频意图区间，支持单步推进、切换自动或手动阅读，或者点击重播某一句对白。需要注意，这里展示的音频区间是根据指令生成的意图范围，不等于解码后的真实音频波形时长，暂停自动阅读也不会冻结已经派发出去的演出动作。关于如何在画面上点击拾取源码位置，见[在运行画面中修改](/docs/editor/authoring#在运行画面中修改)。

## 存储与资源

「存储」面板读取当前预览会话的数据：Web 端展示 Local Storage、Session Storage、IndexedDB 和 Cache Storage；Native 端展示引擎存档、Host 命名空间记录、已挂载 QPK 与驻留资源。支持筛选、分页、查看 JSON、原文或有界十六进制预览并一键复制，其中绿色高亮行表示当前正驻留在内存中的资源。

需要特别留意，Web 开发预览使用的是临时隔离的浏览器分区，停止预览就会清空；目前 Native Demo 默认也跑在 `MemoryBackend` 和 `InMemory Host` 上，关掉会话数据就没有了（正式打包发行的项目会使用持久化的磁盘后端）。把鼠标悬停在存储位置上可以查看当前后端类型，切勿把预览里的临时存档当成正式备份。

Web 端若想在存储面板里看到渲染器句柄、引用计数与估算字节数，需要由项目注入资源查询回调（该估算值不包含浏览器内部缓存和 GPU 显存分配）；Native 端查看引擎存档同样需要接入开发 runtime。切换或停止会话后会清空上一轮的记录。

## Performance 与日志

Performance 面板展示最近 60 秒的 FPS、帧间隔、CPU/RSS 占用以及可用的 GPU 指标。Web 端的 FPS 反映 `requestAnimationFrame` 回调频率，Native 端的 FPS 来自实际提交渲染的帧数（Draw Calls 统计包含合成、阴影和模糊通道）。CPU 占用率只统计预览渲染进程本身（单核跑满为 100%）；系统级 GPU 利用率与进程内存属于不同统计口径，暂不支持读取的指标会显示 `—`。

Debug Console 用来集中展示运行日志、依赖安装输出和错误详情，需要交互式输入指令时请使用集成终端。遇到报错后记得先看第一条原始报错和源码位置，再对照[Editor 常见问题](/docs/editor/troubleshooting)排查。
