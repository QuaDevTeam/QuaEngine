## 源码启动失败

请确认是从仓库根目录执行 `pnpm install --frozen-lockfile` 和 `pnpm dev:editor`。`dev:editor` 会预先构建编辑器依赖、项目模板和本地 SDK；直接拿某次旧的 `dist` 目录来启动，并不能反映当前源码的状态。

核对本机版本是否为 Node.js 22.12+ 与 pnpm 12.3.4。macOS 上如果编译嵌入层报错，检查一下 Xcode Command Line Tools 以及报错中提示缺少的 Electron Node-API 头文件；只有需要运行 Native 游戏预览时，才额外要求安装 Rust/Cargo 和系统链接器。

## 依赖安装或下载卡住

展开安装日志，查看卡住的具体工具名称、请求 URL、HTTP 状态码和第一条报错信息，并排查系统代理/PAC 配置、网络连接与剩余磁盘空间。编辑器托管的运行环境存放在用户数据目录下，不会破坏全局的 Node 或 Rust。遇到网络波动可以先取消再重试，不要为了解决下载问题去删除整个项目目录或写作数据目录。

## 文件无法保存

先排查是不是遇到了磁盘外部修改冲突、文件在外部被删、路径变更或系统权限不足。编辑器里还留着未保存文本时，务必先用「比较差异」看清楚改动，再明确决定「载入磁盘版本」还是「保留本地并保存」，切勿在外部强行覆盖来绕过版本校验。目前编辑器暂未提供崩溃自动恢复草稿和三方自动合并功能，重要修改建议勤按保存并做好 Git 提交。

## 预览起不来或定位不准

| 常见现象 | 排查方向 |
| --- | --- |
| 预览无法启动 | 检查项目根目录的 `qua.project.*`、`dev:web`/`dev` 或 `dev:native` 脚本、依赖是否装齐，以及终端第一条报错 |
| 提示 Native 不支持 | 原生图层内嵌目前仅支持 macOS；Windows 和 Linux 暂未接入且不做截图转发回退 |
| 「到光标」按钮不可用 | 检查 `.qs` 是否有静态编译错误、光标位置是否在当前源文件内，以及项目是否接入了 `editor-core/runtime` 和脚本工厂 |
| 变量或前几章状态不对 | 源码定位只从开发基线重放当前单个文件，不会自动推演前面章节做过的选择 |
| 保存后预览跳回文件开头 | 你修改的当前步骤可能被删掉了、内容变化太大无法匹配，或者此前还没有定位过 |
| 预览没有声音 | 检查工具栏上的预览静音按钮、游戏内音量设置、Web 端是否已点击页面激活、资源加载及 `AudioContext` 状态 |
| 停止预览后存档不见了 | 确认项目是不是使用了临时的 Web 分区或 Native Demo 的内存存储后端 |

## 角色或动画面板没有更新

角色浏览器读取的是已保存文件的静态索引，运行期动态注册的角色或复杂工厂函数可能无法静态解析；另外，修改角色或资源 ID 后不会自动改写剧本里的引用。

使用动画编辑器时，改完关键帧记得先点「应用到源文件」，再按保存。如果剧本里没有静态的 `@PlayAnimation` 调用，需要手动选择预览场景；遇到分支选项时必须在画面里点选才能继续。遇到源码版本冲突时，面板会保留你未应用的视觉草稿，解决完冲突后再重新应用即可。

## 插件、写作与生产打包

插件装完如果没生效，按顺序检查实际安装的依赖、devtools 启用状态、Registry 审查状态以及游戏入口里的 runtime 接线（“安装成功”只代表包已经写进 `node_modules`）。使用 Novel Writer 时，先确认模型提供商配置和额度；AI 生成的内容依然需要人工通读把关，导出归档里的草稿也不等于已审核。

生产打包报错时，重点看第一个失败的步骤和展开的详细日志；关闭面板不会取消后台任务，跳过 Apple 公证也不代表已通过公证。打包成功后请按[生产打包与产物检查](/docs/editor/builds)实际跑一遍产物。

## 提交问题反馈

反馈 Bug 时，请尽可能附上当前源码 commit 或 Editor 版本、操作系统与 CPU 架构、Web/Native 目标、完整复现步骤、第一条原始报错以及一个最小复现工程。如果贴日志、配置文件或截图，记得先把 API 密钥、本机私有路径和未公开的剧本内容删掉，并说明问题是在开发预览、生产目录还是独立安装包里复现的。
