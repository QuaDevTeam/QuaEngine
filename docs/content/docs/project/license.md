`packages/editor/` 目录下的第一方源代码（包括内置角色、动画与写作工具）采用 [MPL-2.0](https://github.com/QuaDevTeam/QuaEngine/blob/main/packages/editor/LICENSE)。这是按目录划分的授权边界，并不是让用户在 Apache 和 MPL 之间二选一。

MPL-2.0 允许商业使用和 Fork。对外分发受覆盖的文件或其修改版本时，需要按协议提供对应的源码与声明；不包含这部分代码的独立文件则可以采用其他许可。用编辑器创作出来的游戏作品本身，不会仅因为使用了这款工具就受限于 MPL。
