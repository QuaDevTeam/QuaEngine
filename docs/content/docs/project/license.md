## 引擎与共享包

除另有声明，编辑器目录之外的引擎、编译器、渲染器和共享包采用 [Apache-2.0](https://github.com/QuaDevTeam/QuaEngine/blob/main/LICENSE)。保留适用版权、许可与 NOTICE 声明。

## 独立 IDE

`packages/editor/` 的第一方源代码，包括内置角色、动画与写作工具，采用 [MPL-2.0](https://github.com/QuaDevTeam/QuaEngine/blob/main/packages/editor/LICENSE)。这是目录范围的许可，不是 Apache 与 MPL 二选一。

MPL 允许商业使用和 Fork。对外分发覆盖文件及其修改时，需要按 MPL 提供相应源码与声明；独立且不包含覆盖代码的文件可以采用其他许可。使用 IDE 创作游戏，不会仅因使用工具就让游戏作品适用 MPL。
