## 推荐创作顺序

先用纯文本跑通一幕的对白与选项，再逐步增加背景、角色、动画和音频。每加入一个会影响存档或跳转的能力，马上验证当前位置恢复与目标跳转。

## 文本与工程各自负责什么

QuaScript 专注把台词、演出指令和选择分支写得清晰直观；复杂的数值计算、项目配置、插件注册、平台服务与发布打包，则放到 TypeScript 和构建配置里处理。

不要在剧本里硬编码本机磁盘路径，也不要从渲染器 UI 直接修改故事变量。只有把角色表情和音频状态同步写进引擎投影，玩家在读档或打开回看时才能恢复出完整的现场画面。
